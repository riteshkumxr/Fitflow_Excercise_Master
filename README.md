# FitFlow AI — Smart Fitness Coach & Motion Tracker

An AI-powered web application for real-time exercise form correction, workout tracking, macro diet planning, and personalized fitness analytics.

---

## 🚀 Key Features

* **⚡ Real-Time Pose Detection**: Form guidance and repetition counting for Upper Body, Lower Body, and Desk posture breaks.
* **🌓 Dark Mode & Light Mode**: Seamless 1-click theme switching persisted in local storage.
* **🔐 Authentication & Athlete Profiles**: User sign-up and login with personal vitals (age, weight, height, fitness goals), dynamic monogram emblem, and custom photo upload.
* **💪 Interactive Workout Library**: Categorized exercises with animated demonstrations, target muscle focus, calorie estimation, and video tutorials.
* **🥗 Macro & Nutrition Tracker**: Daily calorie rings, interactive meal logger, food item search, and target macro calculator.
* **📊 Analytics Dashboard**: Weekly calorie expenditure chart, active streaks, upcoming workout sessions, and milestone achievements.
* **🤖 FitFlow AI Assistant**: Embedded virtual fitness assistant ready to answer training and nutrition questions.
* **📥 One-Click Source Code Download**: Built-in download feature directly in the application.

---

## 🛠️ Tech Stack

* **Frontend**: React 18, Vite
* **Styling**: Tailwind CSS, Lucide React Icons
* **Routing**: React Router DOM
* **Computer Vision / AI**: TensorFlow.js, MediaPipe Pose Detection
* **State & Persistence**: Context API (`ThemeContext`, `AuthContext`), LocalStorage

## 🏃 Getting Started

### Prerequisites
* Node.js (v18 or higher recommended)
* npm or yarn

### Installation
```bash
# Clone the repository
git clone https://github.com/riteshkumxr/Fitflow_Excercise_Master.git

# Navigate to project directory
cd Fitflow_Excercise_Master

# Install dependencies
npm install

# Start local development server
npm run dev
```

The application will be running at `http://localhost:5173/`.

### Building for Production
```bash
npm run build
```
